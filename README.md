# YouTube Tab Lock

A Chrome/Chromium extension that lets you finish the YouTube videos already open in your tabs while blocking new videos.

## Install

1. Open `chrome://extensions` in Chrome or a Chromium-based browser.
2. Turn on **Developer mode**, then choose **Load unpacked**.
3. Select this project folder. Pin YouTube Tab Lock from the extensions menu if you want quick access.

Open the videos you want to watch, click the extension, and choose **Lock current videos**. Each video remains allowed in its original tab, including after a refresh. New video pages and YouTube's in-page video navigation are blocked. Click **Unlock videos** to stop blocking. The lock lasts until you unlock or the browser session ends; closing an allowed tab removes it from the list. YouTube browsing pages remain accessible.

The extension handles standard YouTube watch, Shorts, live, embed, and youtu.be video URLs. Incognito windows require the browser's separate permission for this extension.
